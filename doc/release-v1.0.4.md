# SmallnGinxControl v1.0.4

Дата релиза: 2026-10-10

Git tag: `v1.0.4`

## Изменения

- В таблицах виртуальных хостов и reverse proxy появился отдельный янтарный переключатель ручного отключения из-за неоплаты.
- Перед блокировкой показывается подтверждение «Отключить» / «Отменить». Для каждого nginx-конфига хранится независимая резервная копия; восстановление возвращает исходный файл после проверки и reload nginx.
- Неоплатная страница оформлена в стиле `/var/www/html/maitenance.html`, сообщает, что домен отключён из-за неоплаты, и не показывает `503 Service temporarily unavailable`.
- Контактный текст страницы редактируется через модальное окно в настройках. Изменение синхронизируется с уже отключёнными доменами на локальных и SSH nginx-серверах.
- Обычный режим обслуживания и стандартный `maitenance.html` остаются отдельными от неоплатной блокировки.

## Обновление

- Новый хост: `deploy/install.sh` по умолчанию устанавливает release `v1.0.4`.
- Существующую production-установку обновляйте по [deployment guide](deployment.md). Миграция `0012` добавляет текст контакта в настройки; БД, state-каталог и `SECRET_KEY` сохраняются.

## Проверки

- Новые backend-сценарии: неоплатная блокировка и точное восстановление для host/reverse proxy, валидация и сохранение текста настройки.
- Playwright: подтверждение/отмена, отображение заглушки, восстановление и модальное редактирование контакта.
- `manage.py check`, `makemigrations --check --dry-run` и JavaScript syntax check.
