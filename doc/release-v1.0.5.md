# SmallnGinxControl v1.0.5

Дата релиза: 2026-10-11

Git tag: `v1.0.5`

## Исправление

- Неоплатная HTML-заглушка больше не встраивается в длинный аргумент nginx `return`. Страница сохраняется отдельным UTF-8 sidecar-файлом в `/var/www/html`; конфигурация использует короткий `alias`.
- Sidecar доступен на чтение nginx, обновляется вместе с текстом контакта и удаляется при восстановлении или удалении хоста.
- Конфиг, sidecar и резервная копия меняются транзакционно; при ошибке `nginx -t` исходный сайт остаётся включённым.
- HTTP 503 сохраняется, меняется только содержимое ответа. Обычная `maitenance.html` не затрагивается.

## Обновление

- Новый хост: `deploy/install.sh` устанавливает release `v1.0.5`.
- Существующий сервер обновляйте по [deployment guide](deployment.md). Миграции и каталог state сохраняются.

## Проверки

- Backend: nginx host/proxy блокировка, длина config, sidecar permissions, обновление контакта, rollback и восстановление.
- `nginx -t` на production после деплоя.
