# SmallnGinxControl v1.0.7

Дата релиза: 2026-10-11

Git tag: `v1.0.7`

## Исправление

- Настройка «Сообщение при неоплате» теперь выводится как основное сообщение на странице блокировки сразу под причиной отключения.
- Sidecar-страница больше не содержит отдельный захардкоженный текст «Сайт временно не обслуживается» и дублирующую нижнюю контактную строку.
- При сохранении сообщения ранее отключённые сайты пересобираются из своих резервных оригиналов и получают тот же текст.

## Обновление

- Новый хост: installer по умолчанию устанавливает `v1.0.7`.
- Существующие серверы обновляйте по [deployment guide](deployment.md).

## Проверки

- Проверены рендер sidecar для host/reverse proxy и восстановление конфигураций.
- Playwright проверяет сохранение сообщения в настройках и его применение на странице блокировки.
