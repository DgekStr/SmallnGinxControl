SmallnGinxControlRELEASE v1.0
Nginx operations · self-hosted

Управление nginx без потери контроля.

Единая административная панель для виртуальных хостов, reverse proxy, метрик и нескольких серверов. Конфигурации проходят проверку до применения; операции сохраняются и могут быть откачены.

Release notes

Обзор сервера: состояние nginx, метрики CPU/RAM и сетевой трафик.

Рабочие сценарии

Хосты и reverse proxy

Поиск, фильтры состояния, настройка upstream, редактирование исходного nginx-файла.

TOP-5 трафика

Активные vhost сортируются по отданным bytes-sent; объёмы показаны горизонтальными полосами.

Maintenance без потери vhost

Proxy остаётся в конфигурации и отдаёт страницу обслуживания с 503. Включение восстанавливает исходный файл.

Несколько серверов

Профили изолируют конфиги и метрики; SSH-подключение закрепляет fingerprint хоста.

Метрики и журналы

CPU, память, uptime, RX/TX, ограниченный просмотр журналов и аудит действий.

Проверка и откат

nginx -t, атомарная запись, резервные копии и rollback при ошибке reload.

Self-hosted

Python, Django, SQLite и systemd. Production state хранится отдельно от Git checkout.

Новый хост устанавливается из тега v1.0 через git clone deployment guide и deploy/install.sh.

Для HTTPS на частном IP используется self-signed или внутренняя PKI. Браузеру нужно доверить сертификат; публично доверенный сертификат обычно требует DNS-имя.
