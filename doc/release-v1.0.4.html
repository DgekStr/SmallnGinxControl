Отключение сайта по статусу оплаты.

Отдельное управление неоплатной блокировкой для virtual hosts и reverse proxy с сохранением обычного режима обслуживания.

v1.0.4Релиз · 10 октября 2026

Что изменилось

Отдельный переключатель

Янтарный переключатель в таблицах host и reverse proxy открывает подтверждение отключения из-за неоплаты.

Обратимое действие

Исходный nginx-конфиг сохраняется отдельно; после оплаты его можно восстановить с проверкой и reload.

Собственная заглушка

Страница повторяет дизайн maintenance-страницы FOCUSLENS, сообщает причину отключения и не показывает сообщение 503.

Редактируемый контакт

Текст для связи редактируется из настроек и обновляется на уже заблокированных сайтах.

Обновление

Новый сервер устанавливает release `v1.0.4`. Production-установку обновляйте по инструкции; миграция настроек выполняется через `manage.py migrate` и не заменяет каталог state или `SECRET_KEY`.
